# FHIR-MCP Bridge
Autonomous bridge between clinical FHIR resources and AI agents.

## Features
- Cross-FHIR Resource Mapping (Patient/DiagnosticReport/Observation).
- Autonomous Demo Runner for orchestrated clinical workflows.
- Confirmation gates for side-effect heavy operations (PUT/DELETE).

## Setup
1. `uv run run_server.py`
2. `uv run test_runner.py`
